## test case

1. <u>USB protocol</u> - usb part 변경 시 테스트 필요.
    * USB chapter9 
      + [x] USB3CV Tool 테스트 모두 통과.
    * HID 
      + [x] HID protocol 테스트 모두 통과.

2. <u>USB 인식</u> - usb part 변경 시 테스트 필요. 3회 반복. root hub 이용. 
    * [x] PC를 cold reset 해서, 모두 정상 인식.
    * [x] PC를 warm reset 해서, 모두 정상 인식.
    * [x] PC를 sleep 후, resume 해서, 모두 정상 인식.
    * [x] PC를 hibernation 후, resume 해서, 모두 정상 인식.

3. <u>일반 카드 읽기</u> - USB Vendor HID mode 에서, 10회 반복.(성공률 = 성공회수/총회수 x 100)
    * 빠른 속도 성공률 - 90%
    * 보통 속도 성공률 - 100%
    * 느린 속도 성공률 - 100%
  
4. <u>24% Jitter 카드 읽기</u> - USB Vendor HID mode 에서, 10회 반복.(성공률 = 성공회수/총회수 x 100)
    * 빠른 속도 성공률 - 70%
    * 보통 속도 성공률 - 100%
    * 느린 속도 성공률 - 100%

5. <u>30% amplitude 카드 읽기</u> - USB Vendor HID mode 에서, 10회 반복.(성공률 = 성공회수/총회수 x 100)
    * 빠른 속도 성공률 - 100%
    * 보통 속도 성공률 - 100%
    * 느린 속도 성공률 - 100%

6. <u>10% amplitude 카드 읽기</u> - USB Vendor HID mode 에서, 10회 반복.(성공률 = 성공회수/총회수 x 100)
